TDA Archive — Windows 10/11 x64 taşınabilir paket

1. ZIP'in tamamını bir klasöre çıkarın.
2. TDAArchive.exe dosyasını çalıştırın. Uygulama klasöründeki diğer dosyaları taşımayın veya silmeyin.
3. Kurulum veya bilgisayarda ayrıca Python kurulumu gerekmez. Python çalışma zamanı ve uygulama bağımlılıkları bu klasörde paketlenmiştir.
4. Uygulama çalışırken internet bağlantısı kullanmaz. Arşivler yerel bilgisayarda işlenir.
5. Örnek arşiv samples\ornek.tda konumundadır.

Bu paket yalnızca Windows 10/11 x64 içindir. Windows XP desteklenmez. Paket imzalanmamıştır; Windows SmartScreen uyarı gösterebilir. Dosyayı yalnızca tanıdığınız/güvendiğiniz kaynaktan aldıysanız çalıştırın.

Şifreli TDA arşivleri AES-256-GCM kullanır. Şifre unutulursa kurtarılamaz. PDF, DOCX ve XLSX arşivlenebilir/çıkarılabilir ancak bu sürümde uygulama içinde önizlenmez.
